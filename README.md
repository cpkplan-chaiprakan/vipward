# ห้องพิเศษ โรงพยาบาลไชยปราการ

เว็บนี้ขึ้นโฮสต์เช่าได้ด้วย FileZilla + phpMyAdmin
ไม่ต้องรัน Node, Docker หรือคำสั่งบนเซิร์ฟเวอร์

## ขึ้นเว็บโฮสติ้งจริง

ทำบนเครื่องตัวเองก่อน แล้วค่อยอัปโหลด

1. ในเครื่องรัน:

```bash
cd c:\xampp\htdocs\vipward
npm run build:hosting
```

2. เปิด FileZilla ไปที่ `public_html`
3. สร้างโฟลเดอร์ `vipward` (ถ้ายังไม่มี)
4. ใน FileZilla เปิดโฟลเดอร์ **`public_html`**
5. ลากโฟลเดอร์ **`hosting/vipward`** ทั้งก้อนเข้า `public_html`
   - อย่าวางข้างนอก `public_html` จะ 404
   - อย่าโยนโฟลเดอร์โปรเจกต์จาก XAMPP ทั้งก้อน (`src`, `node_modules`, `docker` ไม่ต้องขึ้น)

เว็บจะอยู่ที่ `https://www.cpkhospital.com/vipward/`

## นำเข้าฐานข้อมูลใน phpMyAdmin

1. เข้า phpMyAdmin
2. เลือกฐาน `cpkhospita_project`
3. กด Import
4. เลือกไฟล์ `sql/vipward.sql`
5. กด Go

จะสร้างเฉพาะตารางที่ขึ้นต้น `vipward_` ไม่ไปยุ่งตารางอื่น

## Git: ขาจริงกับขาสำรอง

- `main` = **ขาจริง** ของที่ใช้อยู่ อย่าลองสีหรือของใหม่บนขานี้
- `dev` = **ขาสำรอง** ให้นายลองแก้สีหรือทดลองฟีเจอร์ ถ้าไม่สวยสลับกลับ `main` ได้

ลองของใหม่ให้แตกจาก `dev` ก่อน แล้วค่อยรวมเข้า `main` เมื่อโอเค

## Docker ใช้แค่ทดสอบในเครื่อง

โฮสต์เช่ารัน Docker / npm ไม่ได้ ใช้แค่ตอนพัฒนาบนคอมตัวเอง
